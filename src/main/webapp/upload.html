Sprint 10 - Upload de fichiers

Requêtes multipart/form-data : le framework lié les fichiers à UploadedFile, UploadedFile[] ou Map<String, UploadedFile>.

Retour au sommaire

Fichier unique + champ texte

Cible : uploadFile(UploadedFile file, @RequestParam("description") String)

Plusieurs fichiers sur le même champ

Cible : uploadMultiple(UploadedFile[] photos) - sélectionner plusieurs fichiers à la fois.

Tous les fichiers, indexés par nom de champ

Cible : uploadMap(Map<String, UploadedFile> files) - deux champs différents ; le commentaire texte est ignoré car ce n'est pas un fichier.

Sprint 3 & 4 - Paramètres de requête

Les paramètres du formulaire sont injectés dans la méthode du contrôleur via @RequestParam, avec conversion String vers int.

Retour au sommaire

Addition : POST /calcul

Cible : postCalcul(@RequestParam("nombre1") int, @RequestParam("nombre2") int)

Paramètre absent

Envoi d'un seul nombre : le paramètre manquant prend sa valeur par défaut (0) au lieu de provoquer une erreur.

Paramètres dans la query string : GET /pageWithParams

Les deux valeurs sont transmises à une vue JSP.
